Ver 正式版本

Ver 1.2 · Windows x64

绘图与节点编辑

  • 位图校准依次点击起点和终点，支持 Ctrl+Z、Ctrl+Y，以及直接输入旋转角度。
  • 默认按 T 切换非位图图层的临时透明度，再按一次恢复各图层原有不透明度。默认不透明度为 50%，快捷键与数值均可在设置里调整。
  • 节点编辑支持 Alt 悬停预览插入位置、Alt+单击插入节点，以及在选中节点后按 Delete 删除。掉头坪支持节点编辑并修复底色显示。
  • 调整自动岔道道肩的裁切和绘制顺序，把道肩放在道面下方，修复透明度预览恢复后出现的异常圆块。斜线阴影统一以工程世界坐标原点和 45° 排布。
  • 优化快速脱离道、交汇处引导线、边线以及末端截断，修正部分急弯自相交、联络道道肩越界和连接断开。

机位、机坪与航站楼

  • 批量绘制普通远机位或通航机位前可查看各机位安全线。自由方向下整排机位保持同一朝向，按住 Shift 时才锁定垂直绘制。
  • 批量绘制可读取工程内保存的方案。编辑菜单提供机位预设管理，支持停止线和作业区样式调整。修复批量绘制普通远机位时出现的 id 错误与无法确认的问题。
  • 自定义机位支持删除组成对象，廊桥回位点可移动。改进批量命名、停止线编辑、通航机位布置和 B 类引入线在极端转角下的同侧衔接。

F8 模拟航图

  • 增加可开关的升降带（Runway Strip），以黑色细虚线显示边界并自动标注长宽。修复与机坪编号同时绘制时出现的 normal 错误。
  • 合并端部徽标以物理跑道端为定位基准，编号居中，磁航向嵌入外圈下缘。优先向跑道中线左右微调，避开道面、进近灯光和邻近滑行道，并改善瞄准点配置。
  • 改进航图布局、注记尺寸及相关标注的显示与导出，补齐多处英文界面词条。

性能与发行

  • 节点拖动复用预览线，减少属性面板重建和强制全视口刷新。场景绘制复用服务车道路径索引与机位引入线几何。
  • 工程校验共享自动标记，并用空间索引筛选交叉候选。ZSAM 对测中场景重建由约 5.78 秒降至 3.74 秒，校验由约 4.02 秒降至 1.34 秒。校验报告逐项一致。
  • 产品版本为 1.2，Windows 文件版本为 1.2.0.0。发行形态为安装包与绿色 ZIP。
