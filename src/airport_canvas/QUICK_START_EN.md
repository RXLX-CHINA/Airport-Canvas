# Airport Canvas Quick Start

Explore the example, then create your own airport project. Author: 刃下狼血

## 1. Open the example

Open the ZSQD example from the File menu. Scroll to zoom and drag with the middle mouse button to pan. Press Alt+Enter for grid-up or Alt+N for true north-up.

## 2. Draw and inspect

Choose a runway or taxiway tool on the left and follow the canvas prompts to place nodes. Press Enter to finish or Esc to leave the tool. Inspect the object properties on the right and press Ctrl+S to save an ACP project.

| Key | Purpose |
|---|---|
| F5 | Inspect destination and direction markings and signs |
| F6 | Inspect taxiway segments and guidance lines |
| F7 | Inspect and edit aeronautical ground lighting |
| F8 | View and lay out the aerodrome chart |

## 3. Export

Use the File menu to choose an export format, view mode and extent. Use Settings → Custom Keyboard Shortcuts to view or change command bindings.
