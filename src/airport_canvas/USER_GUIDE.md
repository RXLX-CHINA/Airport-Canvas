## 21.6 分图层导出

在「文件」菜单选择「导出分层 PSD」「导出分层 PDF」或「导出分层 PPTX」。可选择显示模式、范围或将全部模式导出为 ZIP。三种格式均按所选像素宽度渲染图层。PSD 生成独立透明图层，PDF 阅读器可切换支持的图层，PPTX 将图层放成一张幻灯片上的独立图片对象。需要矢量线条和文字时请选择 SVG。

在「设置 → 示例工程：ZSQD」打开内置青岛流亭示例。示例在新窗口中打开，可通过另存为建立自己的工程。

设置 → 语言可选择简体中文或英文，重新启动应用后生效。偏好保存在软件目录的 config/preferences.aci，包括语言、窗口尺寸与最大化状态。ARP 自动定位位于 F8 机场基准点工具的右侧属性区。

F8 跑道属性可设置尺寸单位和道面材质。标题、频率、机场名称及页脚按固定版式绘制。图内可移动图例、指北针、比例尺和 Note。Note 支持编号与续行缩进。

排版窗口支持 Ctrl+Z 撤销与 Ctrl+Y 重做。左下角为页面浏览导航，右侧上方为裁切导航。参数区滚轮上下滚动页面。

## 21.6 F8 排版与打印

在航图排版中用滚轮缩放，中键或右键平移。右侧页面导航可点击定位。左键拖动比例尺、指北针、图例、Note 和页眉页脚的各组元素。航图内容固定在图框中。

选择纸张与方向后，“缩放以容纳选区”保留整个选区，“按纸张比例裁切”在右侧锁定裁切框比例。左键重画范围，Shift 拖动移动裁切框。

频率字段可输入多行及字母。Note 排在图框内，署名或制图单位放在页脚。图例可按行或列排列，比例尺可选线段、数字或黑白铁道线。热点形状在右侧展开。

# F8 模拟航图

1. 按 F8 或在“显示”菜单选择“航图模式”。右侧空选时可控制项目中各对象类型是否显示。选中图面对象后，可单独修改线条、道面颜色。F8 顶部工具栏的“航图配色”用于调整类型默认值。
2. 左侧选择机场基准点、风向标或热点后，点击图面放置。基准点靠近跑道中点时会吸附，绑定后随跑道中点移动。点击跑道长度或跑道可在右侧切换 m、ft、km。机位号按项目尺寸确定图面字号，随地图同比缩放。热点编号使用与对应轮廓同色的方框。跑道长度沿跑道轴绘制。热点可绘制为普通多边形、自动圆角多边形、矩形、圆角矩形或圆形。多边形点击顶点后按 Enter，其他形状点击两点完成。Esc 或右键取消当前工具。
3. 在 F8 顶部工具栏打开“航图排版”。在右侧导航图拖框选择导出范围，或用“适合窗口”恢复到可见内容范围。左侧同步预览图框。可设置机场名称、四字代码、频率、图号、生效参数、变更类别、Note，以及指北针、比例尺和图例。磁北使用工程磁偏角。
4. 在排版窗口保存后，再保存 ACP。文件导出时选择“航图-F8”，或选择“所有模式（ZIP）”获取全部模式。F8 整场景导出使用保存的航图区域。

# 21.6 停止道、关闭与偏好补丁

选择「停止道」后将鼠标移到跑道端头，出现轮廓提示后点击确认。F6 在机位上用标签显示编号。退出时会将深色模式、网格、导航位置和可见性、连续绘制及窗口尺寸写入 %APPDATA%/Airport Canvas/preferences.aci。

# 21.6 机位标记与界面补丁

「编辑 → 统一描边」和工具栏「描边」可单独启停机位引入线、停止线及编号黑边。选中机位可在属性中设置该机位的黑边。导航窗口默认位于左上角。

# 21.6 外弯、跑道末端与属性滚动

拖动与跑道相连的联络道时，青色虚框显示跑道末端判定范围（每端 60 m 与跑道宽度取较大值，短跑道限制在半长）。有停止道时，琥珀线显示其外端裁切线。点击可见的引入曲线可选中对应路口。右侧属性页支持鼠标滚轮。

# 21.6 审阅、边线与启动补丁

「审阅」分为问题和待核，双击条目定位；表格使用原生滚动条。「机场修正 → 统一 NO ENTRY 尺寸／检查最窄处」提供简洁的设置窗口。可用 start_gui.bat --blank 直接打开空白工程。

# 21.6 路口、描边与状态栏补丁

「编辑 → 统一描边」和工具栏「描边」会批量写入所选类别的对象描边属性，并实际更新画布和导出。批量操作后仍可逐个更改。截断点落在交汇道面附近时，会吸附到交点，按新的路口端部重算圆角与引导线。状态栏在重建图形、审查、截断、文件读写、标识生成和视图切换时显示任务。

# 21.6 大场景显示与 DEMO 补丁

在「编辑 → 统一描边」分别勾选跑道黑边、滑行道黑边和安全线／廊桥／栓井白边。主工具栏「描边」展开相同的三个开关。F6 保留彩色分段和机位编辑线，普通道面填充隐藏。导航窗会在启动后按完整尺寸显示。

# 21.6 道面关闭与机场示例补丁

- 跑道、滑行道、车道和各型机坪的关闭开关位于选中对象的「运行状态」。关闭后，从开放路线驶入的边界入口生成 NO ENTRY 地面标识和禁止进入标记牌。没有接入路线的道面在端部或边界生成提示。重新开放后自动撤除。手绘 NO ENTRY 也自动配对标记牌。
- 选中地面标识，在右侧属性修改「字高」。固定倍率在「设置 → 项目首选项」中调整，留空使用自动值。画布及按固定倍率导出共用项目倍率。
- 「生成标记牌」「编辑选中的标识或标记牌文字」「为选中的目的地与方向标识追加分支」移至「信息引导」。F5 仍属于「显示」。
- 「设置 → 完整机场示例」提供三种虚构、可编辑的机场布局。参考 ATL 中场指廊布局、DFW 航站区分组及 LHR 双跑道与卫星厅。

# 21.6 目的地与方向标识、标记牌与节点编辑补丁

- 从「绘制工具」选取目的地与方向标识或标记牌工具，当前显示模式保持不变。F5 单独切换标识编辑视图。移动鼠标到高亮中线附近，青色圆点显示实际吸附位置。左键确认后，滑行道编号高亮，引导选择目的地。右键取消。
- 选择手动目的地与方向标识，然后在「信息引导」菜单或工具条中点击「追加分支」。也可以直接用该绘制工具点击已有的手动标识，再点击分支。追加内容沿用原标识的行进方向及侧别。
- 选择标识或标记牌，通过「信息引导 → 编辑选中的标识或标记牌文字」修改牌面。组合牌或多分支标识用竖线分隔各段。自动标记牌的修改作为工程覆盖值保存。符号类禁止进入牌没有可编辑文字。
- 跑道等待位置牌默认使用联络道编号，已有自定义编号保留。自动盲降等待位置牌读取相连跑道端号和进近等级，并以已绘制的 B 型等待位置落位。手动放置时，相连跑道提供可选的号码和等级。只有未直接连接跑道时可手动输入。
- 节点编辑模式下选择跑道，拖动青色端点改变方向，松开提交。可用 Ctrl+Z 撤销。Alt+Enter 恢复工程网格朝上，Alt+N 切到真北朝上。

# 21.6 标记牌绑定与真北

「显示 → 标记牌放大显示（固定倍数）」以机场范围计算倍率，倍率和工程落位在缩放时保持稳定。固定屏幕尺寸模式仍单独可选。选中框按当前可见牌面四边更新。PNG/SVG 导出可独立勾选固定倍数放大，关闭即使用原大小。

新绘制的手动标记牌绑定到来源轴线桩号，分割或截断后沿有效路段更新。旧的无来源标记牌可在 F5 从画布或对象树选中，点击「重绑来源」，再点击对应中心线。已删除或截断的绑定目标不再出现在绘图和导出中，恢复后可重新显示。Alt+Enter 恢复工程网格朝上，Alt+N 将工程定义的真北朝上。

# 21.5 缩放性能与标记牌布局

固定尺寸标记牌保持 20 个逻辑像素高。缩放只更新现有牌组的位置。工程尺度和屏幕尺度均为整块牌组预留空间，同时避让道面和其他标记牌。空间不足时，牌组会沿设置侧移动到可用位置。

可退出的跑道连接处会根据已有等待位置生成脱离跑道／位置牌。多条支路在同一个路口汇集时，方向牌自动按左右顺序组成多面板牌组。也可在 F5 手工输入长牌，如 `↙D | ←C | ↖E | @B | D↗ | C→ | E↘`。

Alt+N 使用 Qt 窗口快捷键，使真北箭头垂直向上。工程图基准设置为真北时视图归零，设置了当地网格方向时则按该角度自动旋转。普通机场图的标签省略 F6 字样。进入彩色分段后仍可用 F6 切回。连续绘制位于主工具栏按钮最右侧。

# 21.4 牌面与深色工作区

在「显示」打开「标记牌不按比例显示」，牌面在屏幕上固定为 20 个逻辑像素高。按比例与固定尺寸的牌面都会避开跑道、道肩、滑行道、机坪、停止道与服务车道等已绘制道面。必要时整组牌面向所选侧的可用位置移动。固定尺寸模式只改变画布显示，导出使用避让后的工程尺度。开启「深色模式」可切换工作区外观。连续绘制开关位于主工具栏。

「目的地与方向标识与标记牌」分类和 F5 提供跑道号码／位置组合、CAT 等待、禁止进入、道路等待（停）、位置、脱离跑道／位置组合、跑道出口、滑行位置识别点、方向／位置组合、目的地组合，以及原有的转换频率等待与交叉点起飞牌。跑道号码可录入单端或双端，在所选侧排列位置面板。组合方向牌以竖线分隔牌面，@ 表示位置，例如 `←C | @B | C→`。组合目的地可用 `←04 | 22→` 或 `27·33→`。输入中的箭头只是选择符，最终牌面由矢量绘制。

# 21.3 商业机场、标记牌与显示

顶部「显示」收纳网格、辅助名称、等待标记、保护区、连接预览、导航窗口、描边、标记牌及性能设置。「比例尺」位于「显示」的二级菜单。启用「标记牌不按比例显示」可在远景下放大牌面，工程尺寸和导出尺寸保持原比例。

Alt+右键拖动旋转画布，Alt+Enter 恢复工程网格朝上，Alt+N 恢复真北朝上。右上角模式标签固定在屏幕上，同时显示真北、磁北。工程未设置磁偏角时，界面提示磁北未设。

### 标记牌工具
从绘制工具的「目的地与方向标识与标记牌」分类独立选用工具，或按 F5 打开同类工具的编辑模式。F5 显示彩色滑行道分段及引导标识和标记牌。普通机坪可在属性中选择 APRON、CARGO、RUNUP、INTL、MIL、CIVIL 或 DEICING。货机坪和试车坪工具以两个对角点绘制，自动设置 CARGO 或 RUNUP。

交叉点起飞牌先选入口滑行道锚点，再点所用跑道端，确认经核实的剩余 TORA（米）。对话框初始值是几何估算。跑道等待位置牌在中线选位置后录入牌面编号；转换频率等待点使用 HP 加正整数。两类强制性指令牌使用红底白字。用户设置的牌位仍需根据 MH 5001—2013 的设施与净距要求校核。

# 21.2 标识、显示与画布操作

## 显示与旋转

从顶部菜单打开「显示」，可独立隐藏跑道黑色描边、滑行道黑色描边、安全线／廊桥／栓井白边或标记牌。下拉菜单还可打开 FPS 和进程内存。右下角 FPS 是每秒视口绘制次数，内存为进程常驻内存。按住 Alt 并水平拖动右键可旋转画布，Alt+Enter 恢复工程网格朝上，Alt+N 恢复真北朝上。视图旋转和性能显示属于当前窗口，显示选项保存在工程里。

## 标识编辑

F5 进入或退出标识编辑。选择「目的地与方向标识」「方向标记牌」或「目的地标记牌」，再选择左侧、右侧或两侧。先点击滑行道或机坪滑行道中线，再点击目标滑行道中线、跑道头或机坪区域。若机坪和滑行道重叠，按住 Shift 点击可优先选择机坪。右键取消当前锚点。选中手动标识后可用「重选目的地」更新关联。点「生成标记牌」可启用并恢复自动标记牌。手动标识的来源和目标随 ACP 保存。

自动引导覆盖快速脱离道的反向分支及机坪进出方向。箭头采用八方向矢量轮廓，T 形路口双向指示按左、右顺序排列。标记牌参考 MH 5001—2013 第 9.7.2、9.7.4.3、9.7.4.4 节。自动生成的是平面布置，表 32 净距、附录 H 安装及照明、T 形路口标记牌现场位置仍需校核。

## 末端截断

左键点工具栏按钮选删左端，右键点按钮选删右端。红色虚线预览待删除的一段。画布左键确认，右键或 Esc 取消。

# 21.1 界面与边线修复

导航窗可拖动标题栏，右上角关闭后可通过「导航窗口」复选框恢复。悬停会显示紧凑提示。「场景对象」搜索位于对象列表上方，属性栏各页独立滚动。取消跑道或滑行道的「关闭对象」后，画布会重绘连接处边线。

# Airport Canvas 21.0 · PySide6

Airport Canvas 是以机场图生成为核心的所见即所得机场编辑软件。本版将桌面界面和交互绘图后端迁移至原生 PySide6 / Qt Widgets，沿用20.18版本的机场模型、业务回调和ACP JSON结构。

## 安装、启动和更新

1. 完整解压本包到可写文件夹，推荐使用 Windows x64 Python 3.12。
2. 双击 **start_gui.bat**。已满足依赖时直接打开；首次启动会在程序目录创建`.venv`，使用包内`_wheels`安装依赖。Python 3.12 x64的依赖已离线打包并校验SHA-256，包含PySide6-Essentials、Shiboken、Pillow、NumPy、Shapely、FontTools。其他Python版本需要下载匹配的依赖。
3. 沿用旧工程时，从文件菜单打开原ACP。工程仍为UTF-8 JSON。建议首次另存为一个新ACP，方便对照。
4. 覆盖安装到旧程序目录可运行`python install_gui.py --target "你的原项目路径"`。安装器备份所有被替换的程序文件，保留用户自己的ACP。安装后使用`start_gui.bat`启动。直接运行`python gui.py`要求当前Python已经安装requirements.txt中的依赖。

无需执行PowerShell脚本。启动安装可单独执行`python bootstrap_qt21.py --install-only`；依赖检查为`python bootstrap_qt21.py --check`。依赖安装失败时保留项目文件，错误写入gui_error.log。

## 使用方法

* **F6**：切换普通机场图/彩色编号视图。机位安全线、编号、引入线保留显示；“信息引导 → F6保留机位及引入线”可以关闭该参照层。切换不写入道面几何，不把机位与滑行道合并。拖动和缩放会重新投影参照层。
* **合并选择**：路线编辑合并首尾相接的整条滑行道后，点击任意成员会选中整条链，普通视图显示共同选择框，F6显示青色虚线强调。仅同名但未合并的路线不会加入。移动已合并成员端点不会清除选择关系；“强行独立分支”解除该分支的关系。不同位置不相接的路线仍是各自独立的选择链。
* **末端截断**：左键点击工具栏按钮选删左端，右键点击按钮选删右端。预览显示垂直断面和红色待删段。画布左键确认，右键或 Esc 取消。截断位置距两端至少 1 m。用 Ctrl+Z 撤销，或用「信息引导 → 恢复选中滑行道的截断」恢复原始道面。连接道的实体端点通过节点编辑调整。
* **机坪形状**：“机坪”菜单选择矩形/梯形/自定义多边形。前两种点击两个对角点完成，有轮廓预览；多边形按原方式依次点顶点、Enter完成、右键取消。梯形预设上边收窄，可再通过顶点编辑调整。
* **机坪布尔操作**：Ctrl多选普通机坪，菜单选择并集、交集或差集。差集为最后选中的机坪减去其他选中机坪。交集为空时不改动原对象。孔洞和分离岛保留；结果拆为无孔简单区域放入一个组，便于沿用ACP结构与现有绘图器。Ctrl+Z整次撤销。不支持除冰坪、掉头坪等带专用依赖的预制区域参与。
* **自动方向信息**：“信息引导”菜单分别开关道面信息标志和方向标记牌。按实际相接路线、允许行驶方向与逻辑子段名称生成最近相交滑行道的方向；路线改名、关闭、重新开放、移动后重算。滑行道属性中可关闭该对象的自动方向信息。不会指向单纯在空间上靠近却没有交接关系的路线，也不生成掉头箭头。

## 标准核对及边界

按照用户指定的 **MH5001—2013 8.2.13** 与 **9.7.4.3** 分别实现两种信息显示，未把历史版条号误写成2021版条号。其他既有模块仍保留各自标注的标准版本。

| 尺寸 | 默认字高4m，受限缩小但不低于2m；箭头约2m | 单独物理比例模板，不能套用道面4m字高 |
| 设置 | 按来向可读，位于道面内；空间不足不强制塞入 | 默认在来向左侧；无中间等待位置时按代码选择交叉口前60/40m；已有中间等待位置时优先其延长线 |

方向标记牌当前为二维方案模板：附录H完整字形、表32净距、复杂交叉口全部候选面板排序、自身路线明显转弯的补充面板、对转弯开始切点及所有障碍物的净距检查尚需工程复核；默认横向外移11m、字高0.4m不代表对任意机场类别均已验算。道面字体使用现有字体近似，非标准图26逐字符描摹。自动方向标志不等同施工合规证明。

## 预览与圆角增强中线

增强中线现在使用画面可见的圆角路口网络，而非被隐藏的直角轴线端头。工具允许直接点击转弯弧线；距离预算按弧长计算，并传播到相连分支。预览和提交使用同一套可见路径与距离算法。原连接被删除后，失去来源的增强线隐藏并列入审阅，避免留下悬空旧线。

## NO ENTRY：统一尺寸与最窄处检查

1. 打开“机场修正 → 统一 NO ENTRY 尺寸／检查最窄处”。
2. 查看标志数量、机场指标要求字高、最小可容纳字高上限及限制位置。
3. “按指标统一”使用标准字高，容纳不下时保留审阅告警。
4. “按最窄处统一”使用所有位置共同可容纳的尺寸；若低于指标要求，会明确列入审阅，不代表符合标准。
5. 新建滑行道、增加标志或改变宽度后，再次运行工具重新计算。

检查结合道面宽度、单／双侧布局、标志现有横向偏移，并用实际道面联合几何检验完整红底板，避免只按名义宽度判断。若某位置连最小底板都容纳不下，会要求先移动标志。

## 廊桥与机位间距

预览会计算同朝向廊桥之间的机位布置需求。几何不重叠但翼展加净距放不下时仍可生成，同时显示告警；可减少数量、延长指廊或修改尺寸。默认参考当前场景机型，廊桥属性可单独修改。此检查属于二维预检查，不能代替完整机位安全包络、机型运行和廊桥对接设计。

## 交叉跑道瞄准点和接地带

按跑道重要性保留较重要跑道的标志。开启“整组避让”后，较次要跑道受影响的瞄准点成对移动、接地带整组移动，保留块形和组内纵向间距，不再把条块裁成碎片；接地带同时检查与瞄准点的间隔。无法放下完整组时隐藏该组并提示人工重新设计。关闭此选项可回到原站位和交叉优先中断方式。

标准规定交叉处的标志优先与中断，并没有给出任意平移接地带的通用许可；瞄准点还与入口距离和 PAPI 有关联。因此按本项目要求进行的整组移动会保留审阅信息，不能直接判为规范通过。

## 机坪颜色、编号和图标

默认只在机坪覆盖范围内继承其背景色，机坪外仍使用独立滑行道颜色；路口补角和连接道附加道面也参与颜色统一。取消继承可使用自己的道面颜色。颜色不改变物理几何和编号。

连接工具生成的非传统附着连接可独立编号，自动位置标志和 F6 名称同步。机库引入线同样支持四类构型和中线绑定。

此前新增但没有图标的绘图工具已补上独立透明图标；顶栏操作图标去除实心背景，并保留封闭图形内的白色区域。鼠标悬浮提示继续可用。

选机位，在“建筑与廊桥”页启用“移动时吸附廊桥”。拖动机位边框靠近廊桥端部时出现吸附提示；松开后按“距廊桥端部”参数绑定。以后移动廊桥，机位停止端随之更新。取消“绑定已吸附的廊桥”可脱离，取消“移动时吸附廊桥”可禁止重新吸附。原有机位入口与滑行道中线绑定继续保留。

辅助机位预制包含虚线引导线和机位编号，可选 A/B/C/D；默认不带安全线、停止线、作业区和廊桥。需要这些组成时可在属性中打开。机库预制在成套机位上增加屋顶示意；它不是建筑结构设计工具。

## 名称、位置文字与吸附时机

改滑行道名称或逻辑段编号后，其位置标志更新；机位改名后，辅助编号、场景树的成套机位组名称同步。逻辑分段的自动标志先生成再应用编辑偏移，拖动不会在下一次刷新时丢失。

用选择工具点选位置标志等点状标记后直接拖动，可调整文字标志位置；拖动时会显示预览文字并允许中线吸附。Shift 约束方向；Ctrl/Shift 的多选交互保留。机位箭头形编号继续使用沿弧线成对对称移动的控制逻辑。绑定中线的手工标志保留新的站位及偏移，不会因刷新回到旧位置。

选择对象前不进行中线吸附。吸附发生在创建和实际拖动期间；待选、框选和节点待选时不显示吸附光标。

## 增强型中线

自动等待位置的增强中线沿连接网络按距离传播，包含指向该等待位置的相连分支和显式连接路径。也可用“指定长度增强中线”工具点选一条中线，以点击位置为起点，向 START（起点）或 END（终点）选取长度；生成后在“增强中线范围”页改长度和方向。几何交点或已有显式连接才构成拓扑，未相接的近邻不会自动连接。

分支消耗同一距离预算，不按每条分支重新延伸完整长度；遇到其他等待位置停止传播。侧虚线在穿越路口和等待位置中断，汇聚位置处理 3m 连续段，黑色衬底按增强中线整体绘制。默认自动范围为 47m；自定义范围需结合机场运行条件核对。模型缓存随工程修订失效，不保存旧显示模式的几何。道肩条带的整场缓冲几何每轮只计算一次；结果与旧算法逐顶点一致。

2025 年第四修订案已不再豁免仅用作跑道出口的滑行道。本版不再仅因快速脱离道身份跳过等待位置生成。A 型等待标志的默认跨度仍包括道面及道肩；项目选择只覆盖道面时会列入审阅信息。

## 标志样式

- 全机场 NO ENTRY 字高统一：按机场指标 II，A/B 为 2m，C/D/E/F 为 4m；机场存在多个跑道指标时取适用的较大等级。背景边距至少 0.5m。默认按工程指标 C，已有明确机场／跑道指标时据此确定。超出道面会给出审阅提示，避免为适应窄道面悄悄缩小。

# Airport Canvas Editor18（18.0）功能与使用说明

本节替代17版关于“拆分几何”的说明。现在所有公开的滑行道切割入口均进入逻辑分段，物理删除只在明确的末端截断/删除岔路操作中发生。

## 逻辑分段：只改变编号区间

1. 通过“路线与编号 → 路线编辑”或原分段图标进入。
2. 选择“逻辑分段，保留同一编号”或“逻辑分段，新段独立编号”。
3. 左键点击路线，切线和右侧站位自动更新；可再次左键换位置。输入站位后仍可用“更新预览”。
4. 独立编号时填写不同的新编号，确认提交。

切割仅在原物理路线的属性中记录编号区间，不增加物理路线、连接节点，不重算原曲线，不改变中心线采样、控制点、道面、道肩、交汇圆角或相邻连接点。后续仍通过原节点/连接工具编辑同一条完整物理路线。区间以全线长度比例存储，几何长度调整后按比例随动。位置标志按所属区间显示编号。

点击逻辑段后可以单独改号；合并编号窗口逐段列出编号、所属道面对象和站位范围，可以把同一物理对象内或不同对象上的逻辑段合并成同一编号。合并不焊接或修改几何。旧工程中已有的物理分段仍原样保留，不自动拼接或重构。

![同一物理道面的逻辑编号与实际轮廓（模型图）](preview_logical18.png)

## 末端截断与删除整条岔路

末端截断是明确改变物理道面的独立操作，与逻辑分段分开。

| 选项 | 操作结果 |
|---|---|
| 保留起点侧 / 删除终点侧 | 删除切口到原终点的物理部分 |
| 保留终点侧 / 删除起点侧 | 删除原起点到切口的物理部分 |
| 删除整条选中岔路 | 删除当前物理对象全部道面及其连接；相邻其他物理对象保留 |

删除整条岔路可以在端点点选，不再因为“离端点不足1m”而拒绝。整条对象会显示红色删除预览，确认后才执行。若所选物理对象包含多个逻辑编号，删除整条对象会删除它们全部，须以红色预览为准；直接按Delete不会把某个逻辑编号误当作独立物理岔路删除，而会引导进入预览界面。

局部截断可以恢复完整几何；整条岔路删除后用Ctrl+Z恢复。删除会清理依赖标志及旧截断备份中指向已删岔路的连接，避免恢复主线时重新出现“幽灵连接”。已有截断路线可继续逻辑分段，恢复后编号区间映射回原路线位置。支持旧版截断工程的站位映射。

右键/Esc先取消预览，再次退出编辑。切分与删除都须确认提交，不由左键立即提交。退出路线编辑不会改变F6显示状态。

## 预览性能

鼠标移动只更新切线和红色删除范围，不重绘机场、不重建属性面板、不反复计算道面并集。点击同一条路线时直接更新站位变量和预览。路径命中使用按工程版本缓存的空间索引；F6的实际道面轮廓也按工程版本缓存。提交、撤销或修改几何后会更新缓存。

本机专项测试1000次缓存命中平均约0.043毫秒/次，详见BENCHMARK_EDITOR18.json。该数据不包含原生鼠标事件、窗口绘制、首次缓存或后台模型构建，不等于完整交互帧率。

## F6：实际道面轮廓与逻辑编号

F6仍为独立显示模式。显示联合道面和联合道肩的真实外轮廓，包括原有交汇圆角；其上用颜色区分逻辑编号。名称保持固定屏幕字号，按可见部分定位。关闭F6从当前工程重建普通图，不使用截断前或分段前的图形缓存。F6辅助线不会进入正常图形或导出。

## 服务车道特殊边线延伸

交错白边线不再只覆盖滑行道的承重道面宽度，而覆盖对应中心线至保护边界的范围，并沿服务车道两端增加附加延伸；机坪滑行道及机位滑行通道同样适用。服务车道属性新增“保护范围外附加延伸m”，默认3m，项目可调整。

交错线的白色线段长0.5～1m、宽0.15m及道路等待位置的净距来源于MH5001—2021的6.2.23及表4.9.5。默认附加3m是项目绘图参数，不把它称为标准强制固定数值。它扩展特殊线的适用范围，不改变原道路曲线、道面宽度或滑行道边线。

![特殊边线沿服务车道两端延伸（模型图）](preview_road_transition18.png)

# Airport Canvas Editor17（17.0）新增功能与使用说明

本节取代旧版本关于“彩色分段”和分散截断入口的说明。工程仍为 ACP（UTF-8 JSON），原有几何、节点、曲率、编号关联及撤销重做保留。

## 彩色编号是独立显示模式

菜单“路线与编号 → 彩色编号显示”，或按 F6 开关。它不改变当前工具，不切分、不编号、不截断，也不修改导出内容。屏幕固定字号显示各条滑行道名称，长路线的名称定位到当前可见部分；白色底框与线条分开。普通视图与彩色辅助层使用不同画布标签，辅助图形不会写入正常绘图缓存；返回普通图时从当前工程重新构建道面、中线、边线和道肩。

在彩色显示中使用选择工具，可点选滑行道后查看属性。需要编辑时另开“路线编辑”。要观察其他绘制工具的完整道面预览，请用 F6 返回普通图。

## 统一路线编辑

从“路线与编号 → 路线编辑”进入；顶部原分段图标也进入此界面。原打断编号图标进入同一界面的“新段独立编号”操作。右侧每次只保留一种操作，切换操作会清除尚未提交的预览。

| 操作 | 是否改变几何 | 编号结果 | 提交流程 |
|---|---|---|---|
| 整分支独立改号 | 否 | 所选分支脱离原编号关联，位置标志同步 | 选分支、输入编号、确认 |
| 拆分几何，保留同一编号 | 是，保持接缝连续 | 两段仍属于同一编号 | 选位置、检查切线、确认 |
| 拆分几何，新段独立编号 | 是，保持接缝连续 | 原起点段保留编号，终点段使用新编号 | 选位置、输入不同编号、确认 |
| 末端截断 | 删除指定侧 | 保留段编号不变 | 选位置、选保留侧、检查红色删除预览、确认 |
| 合并编号 | 否 | 指定若干段统一编号 | 打开选择列表、勾选、确认 |
| 恢复完整几何 | 恢复截断前的线及关联 | 保留原工程依赖 | 选截断路线，点击恢复 |

切分和截断：点击路线内部先预览，不会立即修改工程；也可输入站位后按“更新预览”。粉色横线表示切口，红色虚线表示将删除的部分。START=保留起点侧、删除终点侧；END=保留终点侧、删除起点侧。至少距离两端1m。修改站位后必须更新预览，才能提交。

右键或 Esc 首先取消未提交的预览，再次退出编辑；“完成路线编辑”直接结束并取消预览。Ctrl+Z/Ctrl+Y 撤销重做。预览后工程发生变化，预览自动失效，不能用旧站位提交。截断仍可恢复时，须先恢复完整几何才能拆分，避免子段复制整条恢复备份导致重复道面。

路口属性中的截断入口也转到此预览流程，不再与单独属性字段竞争。原站位直接切分按钮已移除。切分保留既有曲线分割、连接节点与位置标志站位迁移；合并编号保留原来的智能推荐和手动勾选。

## 人行横道

横道只有一份参数化图形；默认条纹宽0.4m、净距0.6m，通道进深4m，可在属性调整。横跨宽度跟随所吸附的道面。偏斜改变跨越方向，条纹本身仍沿道路方向。橙色偏斜手柄和选择框的旋转手柄均进入同一偏斜逻辑，不再做一次会被吸附同步覆盖的普通对象旋转。拖动时隐藏原标记及其底纹，提交后替换原几何，取消恢复。

## 交叉跑道与跑滑交汇的标志

按6.2.1处理标志优先级：精密进近优先于非精密，非精密优先于非仪表。同类别由已有“同级跑道标志优先级”决定；未区分时按工程中的跑道顺序作为绘图兜底，工程设计时应明确指定优先级。

保留重要跑道标志，次要跑道在重合道面范围中断，包含手工关联的瞄准点、接地带及其黑色底纹；边线按照交汇边界中断。滑行道穿越跑道不移动跑道瞄准点和接地带。标志依据入口、入口内移、LDA和标准站位生成；不会为滑行道或另一跑道随意前后挪动。接地带继续采用150m网格，与瞄准点重合或其50m范围内省略；非精密指标Ⅰ=2的附加一对按瞄准点后150m处理。

先确定真实可见的跑道标志，再裁切滑行道黄线，避免被隐藏的次要跑道标志留下多余黄线断口。与跑道中线及等待标志交汇的黄线仍按规定保留0.9m净距；入口条带按专门规则保持黄线连续。

![交叉跑道及跑滑交汇模型示例](preview_intersections17.png)

## 停止标志、安全线与整体道肩

无引导停止标志保持标准6m侧向横线及X定位，不缩小字样或把标志移到错误位置。机位属性新增“安全线容纳无引导停止标志”，默认开启，安全线窄端会扩大以容纳停止标志，并沿用原斜率控制；可关闭此项目几何设置。扩大后仍需检查相邻机位和设施净距，自动包住标志本身不代表安全评估通过。

![停止标志与安全线模型示例](preview_stop17.png)

道肩条带从整个道面外边界及道肩并集计算，按0.9m条带的完整涂色面积裁切，不再仅抽样检查各条路线中心。跑道、机坪、其他滑行道和道路的已有道面均不得被条带覆盖；等待位置附近的避让也按标志全宽检查。最大长度7.5m，通常距道肩外缘1.5m，窄道肩按标准短者规则处理。

服务车道与滑行道、机坪滑行道、机位滑行通道的交汇统一生成交错白边线。驶入方向可自动生成道路等待标志，并根据表4.9.5中对应的中心线至物体距离定位，机位滑行通道使用专门列；道路属性可关闭自动等待标志。未指定等级时按场景翼展推导，这是设计候选而非实地批准。已有车道标记和横道会参与避让，空间不足时不强行重叠。尾流标志保留原来的一键/自动开关。

## 1. 软件介绍与启动

Airport Canvas 是用于生成、编辑和导出机场平面图的桌面编辑器。跑道、滑行道、机坪、机位、服务车道及其标记共享同一套场景与绘图数据。审阅信息放在状态栏和审阅界面，绘图区用于所见即所得编辑。

解压完整文件夹后双击 `start_gui.bat`，或在解压目录运行：

```powershell
python gui.py
```

需要 Python、Pillow、NumPy、Shapely；Windows CPython 3.12 AMD64 的部分几何依赖随包提供。其他环境按 requirements.txt 安装。图标为 AirportCanvas.png / AirportCanvas.ico，透明外背景、没有底部标题，保留深蓝图标底板及白色标线。

打开指定工程：`python gui.py "D:\Airport\MyAirport.ACP"`。要更新已有程序目录，可运行 `python install_gui.py --target "C:\Users\ASUS\Desktop\Runway_Generator"`；安装器先备份被替换的程序文件，不替换用户命名的工程。

## 2. 文件、保存与兼容

新工程默认后缀 `.ACP`，内容仍为 UTF-8 JSON，原有 format/version/场景结构保持兼容。文件菜单也能打开旧 `.airport.json` / `.json`。首次保存旧格式工程时选择 ACP 路径，不会自行覆盖原工程。

保存记录对象几何、组、属性、连接关系、机位交汇点、编号沿线位置、标记覆盖和首选项。Ctrl+S 保存；Ctrl+O 打开；Ctrl+Z / Ctrl+Y 撤销、重做。导出图片不能替代可继续编辑的 ACP 工程。

## 3. 界面、分类属性与导航

所有组件的右侧属性按“基本、几何、标记、外观、关联、操作”多页展示；每页独立滚动。名称与说明放基本，尺寸和位置放几何，编号/停止/机位引入放标记，颜色和描边放外观，入口绑定与对象关联放关联，生成组合/子元素选择等按钮放操作。切换对象时尽量保留当前分类。

左侧继续按预制绘画和标记分类组织工具，图标悬停显示用途。场景树可滚动。导航小窗可拖动或隐藏，右上角×采用居中大字。比例尺支持米/英尺，底纹按当前实际尺长收紧，不再固定占用一大块区域。

初始窗口根据屏幕可用工作区设置宽高和位置；Windows工作区扣除任务栏，低高度屏幕不再固定打开980像素高窗口。

## 4. 选择、自由移动、缩放与旋转

单击选择对象，普通内部或空白拖动默认框选。Ctrl/Shift可追加选择；右键或Esc取消当前未提交动作。

光标位于选择框边框的空段时显示移动光标，拖动可自由移动；不按Shift时不强制水平、垂直或45度。八个方形手柄负责改变尺寸，独立圆柄负责旋转，中心十字也可移动。方柄与边框空段用途分开。

调整尺寸默认使用共同倍率，保留组件内部各斜线的斜率与曲线相似关系；拖一个方向的手柄时，另一方向联动。机位安全线在修改机型宽度时，也通过保持已有斜段斜率来调整斜段长度。

机位主体可以自由移动，但引入线入口保持原滑行道中线绑定，因此引入线会随新机位方向更新。只有手动拖入口控制点，才可能解除该入口绑定；距离原滑行道中线不超过吸附阈值时重新吸附。阈值在关联页设置，默认2m。原滑行道不因移动主体而自动换成别的滑行道。

## 5. 跑道与编号

跑道通过两点确定轴线；右侧设置宽度、道肩、进近类别、入口内移、停止道、关闭状态和标记。自动编号依据工程北向、输入磁差与跑道方向计算；软件不会自动知道真实机场磁差。

手动输入合法一端编号时，可启用另一端同步；R 对应 L，C 对应 C。可分别关闭编号和后缀同步。平行跑道一键编号仍需按实际平行组、运行方向人工核对。

中心圆外径为跑道宽度的一半，即外半径 W/4；线宽跟随跑道中线。圆内中线取消，圆附近额外净空为可调项目参数，默认3m，不能把此默认值称为标准强制值。

每端的“临时内移”决定是否绘制临时入口箭头列。内移入口横线始终为白色，描黑边位于其下。停止道向跑道外延伸，黄色折线朝内，默认浅灰底。交叉跑道的道面保持连续，标记按主要跑道优先关系让路；精密进近为同一类别，不能仅按 I/II/III 自动判断优先顺序。

## 6. 滑行道、快速脱离道与连接

滑行道按多段折线绘制，Enter 完成后自动生成圆角曲线。右侧选择滑行道、联络道、机坪滑行道或机坪入口等类型。节点编辑保留折线顶点和每个拐点的半径手柄；不会把全部曲线采样点暴露成节点。

各种滑行路线均可吸附已有中线；连接跑道的滑行道可勾选快速脱离道，仍需完成正确的跑道和接收滑行道连接。快速脱离道适配不成功会给出提示，勾选不是合规认证。手动调整连接后，跑道端延伸方向依据跑道端口方向而不是首段细小切线判断；接收滑行道反向分支也有引导线和 NO ENTRY 标记。

普通连接工具有预览；路口可选择显示哪些转向引导线。滑行道道面不伸入跑道，进入跑道的部分为引导线；跑道端口外的道肩切平。机坪开口处的滑行道边线裁去，包括绕过公共边线计算的独立 TWY_EDGE 标记；开口外正常边线保留。

## 7. 分段、命名组合与指定末端

“打断编号/分段”在鼠标处显示垂直于中线的预览。分段产生独立编号对象，画面不留道面接缝。Ctrl+M 可将同名或相接小段纳入共同命名关系，统一名称而保留各段节点编辑。

把某路口设为末端时，在右侧选择目标滑行道，再选择“截去起点侧”或“截去终点侧”。起点、终点按该路线原绘制方向区分。点击设为末端后，仅截去所选滑行道的该侧，其他穿过路口的路线继续存在；被截段上的连接和附着标记相应处理。

选中该滑行道可取消末端并恢复截断前的数据，或使用撤销。恢复的是设置末端时的快照，不会自动合并快照之后对被截部分的其他编辑。

## 8. 等待位置、标记吸附与描边

本版按 MH5001—2021 第四修订案恢复：跑道等待位置标志默认横跨滑行道道面及道肩全宽。打开旧工程时也迁移原版仅覆盖道面的默认选择。A、B 类附着等待标记随所属道面和道肩宽度更新；遗留项目的例外选择会保留审阅提示。

等待标记可单击吸附中线，方向垂直点击处的中线；块状标记可选择侧别。中线与等待标记的让路净距不把黑边计入。增强型中线使用整体黑色底边；等待标记用一块整体黑底，而不是分别给每条黄线加黑框。

跑道号码及其黑边位于进入跑道的黄色引导线之上。机位红色安全线和桩井采用白色描边。所有标记的可选黑边功能仍由对象属性或全局设置控制；红色安全标记按其白边规则处理。

## 9. 绘制成套机位

选择机位预制工具，先点滑行道中线作为入口，再点停止位置；右侧选择 A/B/C/D 引入类型、机型尺寸、廊桥等。引入半径的新建默认值提高到35m，这是可调绘图初值，实际半径仍受可用长度约束，不是标准统一半径。

机位形成实际组，包含定位对象和生成子元素。整组可移动、缩放、旋转；右侧或树中选择安全线、停止线等子元素可单独修改。生成项仍跟随父对象，若要自由绘制，可转换为可编辑子对象。脱离自动生成后应自行维护其后续几何。

安全线大头开口供飞机进入，小头封闭。小头直段默认15m，增加其长度只延长直段，不改变斜段斜率。廊桥活动区贴合安全边界，沿机位方向延伸；另一侧默认作业等待区采用镜像关系，附轮挡放置区。这些空间必须根据实际机型、设备和净距复核。

## 10. 完整机位引导线、对称编号与控制点

选中机位后拖动入口或共享交汇方点，调整引入构型。按住Shift时从起拖点约束鼠标方向。入口控制点在阈值内吸附原滑行道中线，超过阈值可以明确脱离；主体移动本身不会解除绑定。共享交汇点保持在机位对称轴上。

编号标记直接沿其所属完整引导线拖动。两侧通过共同弧长比例和机位轴镜像定位，不再分别按任意X/Y偏移。线条先保留完整轴线，再按编号五边形及净空范围裁切，因此编号改变后，断开位置随之变化；所有穿过该标记的引导线都让路，不只是原来的两小段。

旧版编号平移覆盖在首次打开时投影为沿线位置。A/B/C/D均保留独立构型，辅助机位同样可以在标记页选择四种引入方式；辅助属性仅决定虚线等角色，不限制构型选择。修改构型不会强行套用另一构型的交汇覆盖数据。

## 11. 停止线与机型列表

机位停止线列表允许添加、选择、隐藏和删除多条停止线；每条可调整站位、侧向偏移、旋转、长度和类型，并手工输入机型列表。显示机型名称本身，不自动增加列表序号。机型字高默认0.2m，基于标准建议0.15～0.3m。

有引导停止线设于相应鼻轮停止点，与对准线成直角，长度不小于2m、宽度不小于0.15m。机型文字的基线跟随停止横线，在横线旁成行排列、方向与机停放方向相反，整体矩形黑底可选。

无引导停止标志依据图6.2.16-8分开绘制：对准线处的短横线约2m，侧方STOP横线6m；侧方横线的内端到对准线距离 X 按飞行区指标 A/B=8m、C=11m、D/E/F=16m，STOP文字高2m，底框高2.5m，文字底框与横线之间留0.1m。不能将6m参数用作中心短横线长度，也不能把X误当侧方长线的中心位置。实际停止参考点是左座飞行员座席，而非鼻轮。

停止线列表提供 T、十字、横杠及无引导图形以适配绘图；这些编辑类型不代表标准定义了四种同级停止线。修改图形不会自动验证具体机型驾驶舱与鼻轮之间的距离。

## 12. 组合机位

选中机位，在右侧点“建立组合机位”，选择2套或3套、平行或非平行、主要机位为中间或两侧，并输入左右间距和非平行角度。生成后仍在同一组，子机位可分别选中编辑机型、入口、停止线等。

依据6.2.16(8)，主机位引入线连续，辅助机位断续；主机位安全线为红实线，辅助为红虚线；两侧编号增加L/R。3套布局的中心机位与两侧机位互斥，两侧之间不因属于同组而被错误设为互斥。2套布局设为替代使用。

初始辅助机型长度和翼展取原机位的75%，只是方便区分的项目初值，应修改为真实机型尺寸。间距、斜角、扫掠及同时使用净距需要人工复核，程序不会据模板宣称已满足所有组合运行条件。已有组合组禁止重复一键生成，避免无限叠加；可直接编辑组内对象。

## 13. 服务车道与剪切式人行横道

服务车道仍按折线圆角绘制，双向两车道，中线为虚线，交汇处按道路逻辑生成转向引导，服务车道不打断飞机滑行道边线。交错边界使用两行棋盘格，限速、尾流提示按车道尺寸缩放，行驶方向在首选项设置。

人行横道吸附道路或滑行道中线，悬浮显示真实条纹预览，单击放置后跨整个道面。倾斜现在是“剪切”，不是旋转：条纹的长边仍平行道路中线，条纹的排列方向倾斜横跨道面。

选中后拖动横道边缘的黄色菱形手柄，或修改几何页“横跨方向倾斜角”，改变剪切。角度范围为-80°～80°，避免接近90°时形成无意义的无限延伸。整体旋转不再用于表达横道倾斜。

## 14. 机坪、掉头坪与除冰坪

机坪按多边形绘制。滑行道进入机坪的开口处不画封口边线。掉头坪采用直角梯形外形并可选择侧别，靠跑道端口侧道肩平切。

除冰坪先点所属滑行道，再点外侧角点，预览包含道面、通行路线及出口中间等待位置。右侧设置宽深、机型指标、转弯半径、活动净距、等待位置距离、坡度及收集设施。无灯光实现。

自动底色同步默认开启：优先识别除冰坪主体所在的机坪多边形颜色，没有包含机坪则采用连接滑行道的道面颜色。背景颜色变化后同步；取消“自动同步所在道面颜色”后可自定颜色。曲面边界重叠或多块不同底色相交时按包含关系选取，不做图像像素取色。

## 15. 单独线条、标记和关闭

单独PATH线条也采用折线绘制、自动圆角，节点编辑可单独调整拐点半径；POINT类单击放置，AREA类多点圈定。独立标记可以设置尺寸、侧别、颜色及描边，吸附标记随父对象重算方向与宽度。

跑道/滑行道关闭时绘制相应关闭标记，按关闭规则隐藏相关标记，进入关闭道面的引导线裁去；连接指向关闭对象时不继续生成误导性引导。关闭的绘图标签不能替代真实运行关闭手续。

## 16. 无固定尺寸上限的导出与进度

文件菜单选择PNG/SVG后设置像素宽度、DPI、全机场/当前视图/选中范围、透明背景及米/英尺比例尺。高度保持范围比例。使用当前标签、设施和保护区图层的显示状态。

取消原来的30000像素宽度和2400万像素固定阻止规则。超过建议像素预算时仅显示内存警告，不因固定阈值禁止导出。仍需正整数尺寸；实际可完成大小取决于内存、图像库和文件系统，内存不足会报告失败。

导出在后台使用场景快照，状态栏显示阶段和进度条；计算几何、绘制、编码和完成分别更新。期间继续编辑不会改变正在导出的快照。同一窗口一次导出一个任务。先写临时文件，成功后替换目标，避免失败留下半张正式图。

PNG的DPI是打印元数据，清晰度主要取决于实际像素。SVG保留矢量道面和线条，文字作为透明图像嵌入。透明导出只去掉画布背景，保留道面本身。图标使用1254×1254透明源图，并附16～256像素的独立PNG和多尺寸ICO供系统直接选用，避免反复由Tk缩放同一张大图。

## Editor16（16.0）：编号分段、停止线与交互修复

### 滑行道编号分段视图

1. 点击顶部工具栏原“滑行道编号分段”图标（悬浮查看名称）。
2. 画面切换为简化路线骨架：隐藏复杂道面标记，不同编号用不同颜色，同编号同色，右侧有图例。此视图只用于编辑，不改变机场图或导出样式。
3. 默认选择“点选分支 / 独立编号”，点击某一条分支的彩色线，右侧输入编号，按“此分支独立使用该编号”。该分支脱离原编号关联，其他分支保持原编号；与之关联的位置标志同步更新。请在离开路口中心的位置点击，避免重叠线难以分辨。
4. 需要从一条完整滑行道中切出一段时，选择“点击切分”，移动鼠标查看垂直切线，单击确认。切分后保留曲线连续性和连接关系，点选需要的段落再命名。切分点必须距离端点至少 1 m。
5. 若要把短段重新纳入同一编号，点击“智能合并为同一编号…”，在既有合并界面选择需要的线路。
6. 点击“完成并返回机场图”或按 Esc 退出。Ctrl+Z 撤销切分和独立命名。

### 终点侧截断

选中滑行道，在几何页的“指定末端截断”中输入截断站位，选择 START 或 END。START 表示保留起点到截断点，END 表示保留截断点到终点。按“预览截断位置”显示粉色切线，再按“应用截断”。可用 Ctrl+Z 撤销，或“恢复完整滑行道”恢复截断前线路。路口设置中的截断操作也会按当前路口位置重新定位，不使用过时站位。支持原始折线和带控制点的曲线。

### 停止线与标签

无引导停止标志按 MH 5001—2021 图 6.2.16-8 修正：侧方横线长度 6 m，X 量到横线外端，A/B 为 8 m、C 为 11 m、D/E/F 为 16 m，STOP 字高 2 m、黑底高度 2.5 m。机型标签保持黄色及可选整体黑底，文字与飞机停放方向相反，按停止线旁的共同边缘对齐，并与线条留出净距。字高默认值仍为 0.2 m；标准推荐范围 0.15～0.3 m，不随画面放大改成与 STOP 同高。

A/D 构型在旧编号牌断口附近使用延长的切向过渡，移动编号牌只改变完整曲线上的遮断位置，不重新拼装断口。两侧编号继续镜像移动。拖动画布时重新定位选择框及手柄；离开适用模式清除旧框。人行横道倾斜预览会隐藏原标记，提交后用新的几何替换，取消则恢复原标记，避免直线版本叠在预览下面。

## 20.4 连接道编辑补充

普通视图或 F6 彩色分段视图中，使用选择或节点编辑工具点击连接道中线，可独立选择该连接道。拖动端点可沿所连道面的中线调整交汇位置；拖动粉色控制柄可调整曲率。在属性页修改独立编号，或选择“改为直线 / 恢复曲线”。直线没有曲率手柄，移动端点仍保持直线；需要弯曲时先选择“恢复曲线”。旧式附属连接的几何仍属于对应分支滑行道，编辑其端点或控制柄会同步更新该分支道面。

F6 下选择“连接并预览”，先点击起点中线，再移向目标中线，显示粉色预览与终点吸附圆，第二次点击确认。右键取消。连接预览开关也适用于此模式。

廊桥吸附以机位活动区内原有回位圆中心为锚点，平移整套机位，圆心与廊桥头部重合。不会单独移动回位圆，不改变机位长度、方向或内部相对位置。此前为机位末端预留的廊桥偏移参数已从属性页移除。


选择子段：若画面中子段较短或难以点选，可在右侧“当前逻辑子段编号”中使用“选择子段”下拉框，切换到目标子段，再编辑“子段编号”。下拉选择只改变编辑目标，不修改工程几何或创建撤销记录。

## 21.6 引导线与界面修补
- 在「显示」打开或关闭网格，普通视图和 F5/F6 共用同一套浅色、暗色网格。导航窗按已存偏好在画布就绪后显示。项目首选项把显示操作和图面参数分组。导航标题可拖动，切换主题时保持位置。
- 选中岔路口后，在右侧「标记」查看直行和转弯引导线；转弯开关按路线端点列出。使用中线吸附放置点式与横向标记时，截断后生成的转弯中线也可以作为定位基准。
- 拖动边框侧边手柄只改该轴，拖角自由缩放。按 Shift 拖角保留原宽高比，按 Shift 拖边使宽高相等。
- 在「编辑 → 布尔运算」对同类普通机坪或航站楼主体做并集、交集、差集。做差集时先单选被减对象，再按 Ctrl 选中减去的对象。并集合并航站楼编号，归并关联并为廊桥顺序编号。结果可撤销。
- F6 机位号避开停止线。自动立式标记牌只在相邻道外空间内排版，若近处放不下，当前显示尺寸下暂缓绘制。审阅的地面文字字高项目不应用于立式牌。

## 21.6 弯道增强中线和岔路标记牌

指定长度增强中线时，点击可见中线，选择起算方向和长度。两点绘制时，依次点击两处可见中线，系统搜索连接两点的可见路径。经过有转弯引导线的交汇处时，沿可见转弯路径延伸。直行线设置和等待点继续影响可延伸范围。自动方向牌在各来向上按可通行岔路分别生成。排版沿用道外就近规则，空间不足的牌会暂缓显示。

## 21.6 快速脱离道统一编辑

连接滑行道可在属性中选择滑行道类型。选择连接生成的快速脱离道，或两端均已锚定的手绘快速脱离道，然后在几何栏打开“两端半径与直线段”。正反向可分别设置跑道端半径、滑行道端半径和直线段目标长度，填 0 自动拟合。蓝色预览为正向，红色为反向，外侧线表示道面边缘。点击应用提交。拖动端点、顶点和控制柄时先预览，松开左键提交。两点增强型中线的预览跟随可见弧线。

## 21.6 滑行道类型即时提交
