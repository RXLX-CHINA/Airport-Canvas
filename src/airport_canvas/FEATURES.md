# 软件功能介绍 · Airport Canvas v1.0

Airport Canvas 是用于绘制、编辑和导出模拟机场图的桌面软件。

| 功能 | 可以做什么 |
|---|---|
| 机场绘图 | 绘制跑道、滑行道、机坪、机位、服务车道、航站楼及其他建筑。在画布编辑节点，在属性栏修改参数。 |
| 滑行引导 | 编辑滑行道分段、转弯引导线、等待线、目的地与方向标识和标记牌。 |
| 助航灯光 | 在 F7 编辑灯光对象、构型及动画开关。 |
| 航图排版 | 在 F8 设置航图配色、机场基准点、热点、图例、比例尺及裁切范围。 |
| 工程与导出 | 用 ACP 保存工程。导入校准位图作为底图，并按模式导出 PNG、SVG 或灯光 GIF。 |
| 编辑环境 | 中英文界面、深色模式、自定义快捷键和工程审阅。 |
