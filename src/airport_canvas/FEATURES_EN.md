# Software Features · Airport Canvas v1.0

Airport Canvas is a desktop editor for drawing and exporting simulated aerodrome plans and charts.

| Feature | What you can do |
|---|---|
| Aerodrome drawing | Draw runways, taxiways, aprons, stands, service roads, terminals and other buildings. Edit nodes on the canvas and parameters in the inspector. |
| Taxi guidance | Edit taxiway segments, turn guidance lines, holding markings, and destination and direction signs. |
| Aeronautical ground lighting | Edit lighting objects, configurations and animation settings in F7. |
| Chart layout | Configure the palette, aerodrome reference point, hotspots, legend, scale and crop in F8. |
| Projects and exports | Save editable ACP projects, import calibrated bitmap backgrounds and export PNG, SVG or animated lighting GIFs. |
| Editing workspace | Switch between Chinese and English, enable dark mode, customize shortcuts and review project issues. |
