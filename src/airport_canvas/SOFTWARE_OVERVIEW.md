# Airport Canvas 21.0 · PySide6

Airport Canvas 是以机场图生成为核心的所见即所得机场编辑软件。本版将桌面界面和交互绘图后端迁移至原生 PySide6 / Qt Widgets，沿用20.18版本的机场模型、业务回调和ACP JSON结构。

## 安装、启动和更新

1. 完整解压本包到可写文件夹，推荐使用 Windows x64 Python 3.12。
2. 双击 **start_gui.bat**。已满足依赖时直接打开；首次启动会在程序目录创建`.venv`，使用包内`_wheels`安装依赖。Python 3.12 x64的依赖已离线打包并校验SHA-256，包含PySide6-Essentials、Shiboken、Pillow、NumPy、Shapely、FontTools。其他Python版本需要下载匹配的依赖。
3. 沿用旧工程时，从文件菜单打开原ACP。工程仍为UTF-8 JSON。建议首次另存为一个新ACP，方便对照。
4. 覆盖安装到旧程序目录可运行`python install_gui.py --target "你的原项目路径"`。安装器备份所有被替换的程序文件，保留用户自己的ACP。安装后使用`start_gui.bat`启动。直接运行`python gui.py`要求当前Python已经安装requirements.txt中的依赖。

无需执行PowerShell脚本。启动安装可单独执行`python bootstrap_qt21.py --install-only`；依赖检查为`python bootstrap_qt21.py --check`。依赖安装失败时保留项目文件，错误写入gui_error.log。

# Airport Canvas 20.18

本版新增机坪形状与布尔运算、工具栏末端截断、动态方向信息；修复合并选择与关闭/重新开放时的派生缓存。F6彩色分段保留机位及引入线作为参照，仍只编辑独立的滑行道逻辑编号。

## 使用方法

* **F6**：切换普通机场图/彩色编号视图。机位安全线、编号、引入线保留显示；“信息引导 → F6保留机位及引入线”可以关闭该参照层。切换不写入道面几何，不把机位与滑行道合并。拖动和缩放会重新投影参照层。
* **合并选择**：路线编辑合并首尾相接的整条滑行道后，点击任意成员会选中整条链，普通视图显示共同选择框，F6显示青色虚线强调。仅同名但未合并的路线不会加入。移动已合并成员端点不会清除选择关系；“强行独立分支”解除该分支的关系。不同位置不相接的路线仍是各自独立的选择链。
* **末端截断**：点击工具栏“✂│”，悬停显示垂直截断预览与将删除的左端；左键立即删除世界坐标左端，右键立即删除右端。线的原始绘制方向不影响左右；完全竖直时以下端作为左端。截断位置距两端至少1m。Ctrl+Z撤销；“信息引导 → 恢复选中滑行道的截断”恢复原始道面。Esc退出。逻辑编号分段仍不改变实体几何；末端截断则明确改变可见道面。连接并预览产生的连接道仍用节点编辑移动端点，不通过此工具切其实体。
* **机坪形状**：“机坪”菜单选择矩形/梯形/自定义多边形。前两种点击两个对角点完成，有轮廓预览；多边形按原方式依次点顶点、Enter完成、右键取消。梯形预设上边收窄，可再通过顶点编辑调整。
* **机坪布尔操作**：Ctrl多选普通机坪，菜单选择并集、交集或差集。差集为最后选中的机坪减去其他选中机坪。交集为空时不改动原对象。孔洞和分离岛保留；结果拆为无孔简单区域放入一个组，便于沿用ACP结构与现有绘图器。Ctrl+Z整次撤销。不支持除冰坪、掉头坪等带专用依赖的预制区域参与。
* **自动方向信息**：“信息引导”菜单分别开关道面信息标志和方向标记牌。按实际相接路线、允许行驶方向与逻辑子段名称生成最近相交滑行道的方向；路线改名、关闭、重新开放、移动后重算。滑行道属性中可关闭该对象的自动方向信息。不会指向单纯在空间上靠近却没有交接关系的路线，也不生成掉头箭头。

## 标准核对及边界

按照用户指定的 **MH5001—2013 8.2.13** 与 **9.7.4.3** 分别实现两种信息显示，未把历史版条号误写成2021版条号。其他既有模块仍保留各自标注的标准版本。

| 项目 | 道面信息标志：8.2.13 | 实体方向标记牌：9.7.4.3 |
|---|---|---|
| 颜色 | 位置黑底黄字；方向/目的地黄底黑字 | 方向黄底黑字，与黑底黄字位置牌组成组 |
| 箭头排布 | 文字右侧，箭头单独用矢量绘制 | 左转箭头置文字左，右转和直行置右 |
| 尺寸 | 默认字高4m，受限缩小但不低于2m；箭头约2m | 单独物理比例模板，不能套用道面4m字高 |
| 设置 | 按来向可读，位于道面内；空间不足不强制塞入 | 默认在来向左侧；无中间等待位置时按代码选择交叉口前60/40m；已有中间等待位置时优先其延长线 |

自动标志仅给出**最近相接滑行道**，不自动推断通往远处航站楼、机坪或跑道的完整运行路线。真正的目的地标记牌另受9.7.4.4约束，不能因名称中有“目的地”就与其他牌混设。窄道面或过短的进近段不够放置时跳过，须人工补充审阅；不能以自动生成数量代替规范覆盖率。

方向标记牌当前为二维方案模板：附录H完整字形、表32净距、复杂交叉口全部候选面板排序、自身路线明显转弯的补充面板、对转弯开始切点及所有障碍物的净距检查尚需工程复核；默认横向外移11m、字高0.4m不代表对任意机场类别均已验算。道面字体使用现有字体近似，非标准图26逐字符描摹。自动方向标志不等同施工合规证明。

资料来源：[CAAC官方MH5001—2013全文](https://www.caac.gov.cn/PHONE/SJ_IPHONE/JCS_IP/YWLJ_JCS/BZZZ_JCS/GCJSBZ/BZXZ/201511/P020151111506883414047.pdf)，信息标志印刷页63–64、方向标记牌印刷页126–131。另核对[MH5001—2021发布页](https://www.caac.gov.cn/XXGK/XXGK/BZGF/HYBZ/202112/t20211201_210343.html)：新版相应条目为6.2.13和8.4.3，工程使用需明确适用版本。用户提供的Bilibili页面本次无法获取正文，未将其作为已逐图核对的依据。
