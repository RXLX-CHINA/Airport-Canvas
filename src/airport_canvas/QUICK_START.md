# Airport Canvas · 快速入门

用示例熟悉图层，再新建自己的工程。作者：刃下狼血

## 1. 打开示例

从「文件」菜单打开 ZSQD 示例。滚轮缩放，中键拖动画布。按 Alt+Enter 将工程网格转回朝上，按 Alt+N 转到真北朝上。

## 2. 绘制并检查

在左侧选取跑道或滑行道工具，按画布提示放置节点。用 Enter 完成，Esc 退出工具。在右侧检查对象属性，随后按 Ctrl+S 保存为 ACP 文件。

| 快捷键 | 用途 |
|---|---|
| F5 | 检查目的地与方向标识和标记牌 |
| F6 | 检查滑行道分段和引导线 |
| F7 | 检查和编辑助航灯光 |
| F8 | 浏览航图并打开航图排版 |

## 3. 导出成果

在「文件」菜单选择导出格式、视图模式和范围。用「设置 → 自定义快捷键」查看或修改命令绑定。
